A practice project built using C++ and Object-Oriented Programming concepts to simulate a basic university management system.

This project was part of my transition from solving small academic OOP problems to building a larger structured application with multiple classes, files, and relationships between components.

Concepts used:
- Classes & Objects
- Inheritance
- Encapsulation
- Constructors
- Vectors
- File Handling
- Header & Source File Organization

Through this project, I learned the difference between writing isolated OOP exercises and managing a real multi-file project structure, debugging runtime issues, and organizing code on a larger scale.

Current status:
Learning project / work in progress.
